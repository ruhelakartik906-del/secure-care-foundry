# Unicare Final Website Revision

## Goal
Refine the existing website without replacing its routes, enquiry storage, authentication, or SEO architecture. Make Modular Operation Theatre the clear commercial priority and update all public contact information.

## Changes
1. **Company details and contact actions**
   - Replace every placeholder phone, email, office address, and works address with the supplied Unicare details.
   - Update header, footer, contact page, enquiry error guidance, and Organization metadata.
   - Add fixed Call and WhatsApp buttons with safe spacing on desktop and mobile.
   - Add the office map to the Contact page and retain the existing enquiry submission flow.

2. **Navigation and footer**
   - Replace the Products dropdown with a compact three-column mega menu.
   - Add the six Modular OT options only beneath the Modular Operation Theatre family; keep all other products independent.
   - Keep mobile Products navigation expandable with the same hierarchy.
   - Remove Quick Links from the footer; retain Products, Contact, and a controlled list of full SEO locality links plus “View All Locations.”
   - Add a dedicated location directory page so the footer link has a useful destination.

3. **Homepage conversion flow**
   - Refocus the hero and main CTA messaging on Modular Operation Theatre solutions.
   - Redesign the four trust points as a compact professional strip.
   - Keep main products commercial, with Modular OT first and visually prioritized.
   - Strengthen the featured Modular OT section and add a six-card Modular OT options section.
   - Redesign “Solutions for Healthcare Facilities” as responsive icon-led cards.
   - Reorder sections to the requested sequence: facilities before Why Unicare, then process.
   - Remove the Hospital Infrastructure Projects gallery entirely.
   - Add the Client Testimonials area in its place; because no genuine testimonials were supplied, show no fabricated quotes and retain a clear unpublished/admin-managed empty state.
   - Keep the enquiry system intact while adding the requested Modular OT options to the product selector and changing the homepage CTA to “Request a Quote.”

4. **Product and SEO presentation**
   - Keep the Products page free of location content and ensure it only lists products.
   - Add reusable Modular OT option data and connect those options to the parent Modular OT page using stable section links rather than duplicate product routes.
   - Strengthen natural Modular OT terminology in homepage titles, descriptions, internal links, and metadata without keyword stuffing.
   - Preserve all existing product, blog, and location URLs.

5. **Validation**
   - Check desktop and mobile layouts, mega-menu behavior, form fields, contact links, map, footer links, and location directory.
   - Search the project for old placeholder phone numbers, `.example` email addresses, and removed homepage/footer labels.
   - Confirm all linked routes load and the preview build remains healthy.

## Technical details
- Continue reading products, blogs, and locations through the existing data helpers.
- Extend the existing product data with a Modular OT child-options collection; do not add children to other products.
- Reuse the current generated Modular OT image for option cards until genuine option-specific photography is supplied; no false technical specifications or customer claims will be added.
- Keep the existing browser-to-database enquiry insertion and admin enquiry management unchanged.
